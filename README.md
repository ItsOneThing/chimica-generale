# 🧪 Appunti di Chimica Generale - Politecnico di Milano

Questo repository contiene una raccolta di appunti e riassunti della teoria del corso di **Chimica Generale** (A.A. 2026/2027) del Politecnico di Milano, rielaborati e formattati in pagine HTML per una lettura più semplice, pulita e responsive.

L'obiettivo di questo progetto è trasformare le classiche slide accademiche in un formato web navigabile, con formule chimiche/matematiche leggibili (senza l'uso di LaTeX grezzo) e concetti chiave evidenziati.

## 📂 Struttura del Progetto

Il progetto è organizzato con un indice principale e una cartella contenente le singole lezioni:

```text
.
├── index.html          # Pagina iniziale con l'indice delle lezioni
└── folder/             # Cartella contenente i riassunti delle lezioni
    ├── ppt2.html       # Teoria Atomica della Materia
    ├── ppt3.html       # Struttura Elettronica
    ├── ppt4.html       # I Legami Chimici (Parte I)
    ├── ppt5.html       # I Legami Chimici (Parte II)
    ├── ppt6.html       # Forze Intermolecolari e Passaggi di Stato
    ├── ppt7.html       # Leggi dei Gas
    └── ppt8.html       # Soluzioni e Proprietà Colligative
